## 🎯 Principles

- **Offline first.** Incident data stays on your machine. No cloud, no telemetry.
- **Fast on real evidence.** Built for millions of events, not demo-sized samples.
- **Native & portable.** C++ / Qt desktop apps with everything bundled in one installer.
- **Made by a defender, for defenders.** Every feature comes from real investigations.
